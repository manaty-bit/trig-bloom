# TRIG BLOOM — 三角関数の特別角クイズ

sin・cos・tan の特別角を楽しく覚える、一問一答のブラウザアプリです。

## 使い方

- **じっくり練習**：正負の符号と値を選び、答えを決定。単位円と座標を見ながら確認できます。
- **60秒チャレンジ**：答え合わせの単位円なし。不正解・パスで残り時間 **−5秒**、連続10問正解ごとに **＋5秒**。
- **2つの範囲**：基本角（0〜π/2）、全角度（0〜2π）。
- **TeX表記**：π/2 のように分子が1ならπを分子に、11/6 πのように分子が2以上なら分数の右側にπを表示。
- **PC・スマホ**：基本的な画面サイズで1画面に収まるレイアウト。自己ベストは利用端末のブラウザ内に保存。

外部CDN・外部依存のない単一ファイルのアプリです。 `index.html` を開いて使用できます。
