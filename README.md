# TRIG BLOOM — 三角関数の特別角クイズ / Trigonometry Quiz

日本語・英語を切り替えて学習できる、sin・cos・tan の一問一答アプリです。スマホ・PCの両方で利用できます。

A bilingual **Japanese / English** trigonometry game for practicing special angles with sine, cosine, and tangent.

## Play / アプリを開く

- [日本語 / Japanese](https://manaty-bit.github.io/trig-bloom/?lang=ja)
- [English](https://manaty-bit.github.io/trig-bloom/?lang=en)

Tap **日本語 / EN** at the top right to change the language at any time. The current problem, score, streak, and countdown remain unchanged. Language preference is remembered in the same browser.

右上の「日本語 / EN」でいつでも切り替えられます。ゲームの進行、解答、正解数、タイマーは保持されます。言語設定は同じブラウザ内に記憶されます。

## Modes / モード

- **じっくり練習 / Practice** — Answer at your own pace and review the unit circle after each question. / 自分のペースで解き、単位円で値と座標を確認します。
- **60秒チャレンジ / 60s Challenge** — No unit-circle explanation during time attack. An incorrect answer or a skip costs **5 seconds**; every **10 consecutive correct answers** earns **5 seconds**. / 単位円なし。間違い・パスで5秒減、10連続正解ごとに5秒追加。
- **基本角 / Basic angles** — 0 to π/2.
- **全角度 / All angles** — 0 to 2π.

## Math notation / 数式表記

- TeX-style vector math, with stacked fractions.
- Angle format: π/2, π/4, π/6; (2/3)π, (11/6)π when the numerator is greater than 1.
- sin, cos and tan values are exact rather than rounded.
- The game works from a standalone `index.html` without external fonts, CDNs or dependencies.
